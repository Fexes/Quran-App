## Offline source search

Search from any main tab. The shared search covers the complete Quran,
reader-visible Hadith, Azkar, names of Allah, downloaded languages, personal
content, tools, widgets, and live prayer information. Retrieval combines local
INT8 E5 inference, SQLite FTS5, and exact source references.
